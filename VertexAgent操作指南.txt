VertexAgent 操作指南

本指南说明如何在这台电脑上使用 VertexAgent。它是本机编程助手，可以问答、写代码、改工作区里的文件，也可以编译和运行 C、C++、Python、MATLAB。SolidWorks 宏只做检查，不会启动 SolidWorks。


一、启动

1. 双击桌面上的 VertexAgent 快捷方式。
   快捷方式位置：C:\Users\Yuhan\Desktop\VertexAgent.lnk
2. 如果服务已经在运行，快捷方式只打开浏览器。
3. 如果服务没在运行，快捷方式会先启动服务，再打开页面。
4. 本机页面地址：http://127.0.0.1:8765
5. 也可以在程序目录里运行 launch-local.ps1 或 start.ps1。
   程序目录：C:\Users\Yuhan\Desktop\New AI


二、页面有哪些入口

顶部有六个入口：

问答
    普通对话。

创作
    写文章、方案、说明。

代码
    按所选语言编写并改工作区里的文件。编写代码使用 DeepSeek V4.1 Flash。

翻译
    翻译文本。

编译调试
    打开、保存、编译、调试、运行文件。

管理端
    注册 API Key、改工作区目录、查看自身改码记录。左侧「本机设置」进入同一页。

左侧是历史对话。点「新对话」开始一轮新的。点「清空」也会新开一轮。


三、注册 DeepSeek

编写代码前，需要在这台电脑上注册 DeepSeek V4.1 Flash 的 API Key。

1. 打开「管理端」或「本机设置」。
2. 在 API Key 输入框粘贴密钥。
3. 点「注册到本机」。页面会先向 DeepSeek 校验，通过后才保存。
4. 密钥只保存在这台电脑，不要把密钥发到对话里。
5. 点「清除」会删掉本机保存的密钥。
6. 注册只能在本机页面完成，不要从其他电脑的浏览器来注册。

当前选定的模型是 DeepSeek V4.1 Flash。代码和自身改码固定使用它。问答、创作、翻译使用页面上当前选中的模型，请保持 DeepSeek V4.1 Flash，不要改成带 cloud 的名称。

模型下拉里如果出现带 cloud 的名称，那是 Ollama 云端标签。当前账号未开通时，选中后会返回 402。请改回 DeepSeek V4.1 Flash，或改用已经下载到本机的模型。


四、对话

1. 在底部输入框写内容。
2. 点圆形发送按钮，或按 Ctrl+Enter 发送。
3. 生成过程中，输入框上方会显示当前步骤，例如正在读取、正在写入、正在运行，同时逐字显示回复。
4. 进入「代码」时，「深度思考」默认勾选。改参数、改注释这类简单任务可以取消勾选。算法、滤波、优化和疑难报错保持勾选。
5. 代码块是深色卡片。右上角可以一键复制完整代码。
6. 「放入工作区」把当前对话里最后一段代码写入工作区。Python 存为 snippet.py，MATLAB 存为 snippet.m，其余存为 snippet.c。
7. 「引入文件」把文本文件内容追加到输入框。文本最多保留约 2 万字。如果选的是图片，则作为图片发送。

写代码时，先在输入框旁的「代码」里选择语言：C、C++、Python、MATLAB 或 SolidWorks。代码模式会把这个语言一并发给助手。

助手交付代码时，回复保持很短：一句说明文件路径和行数，一段完整代码，最多再加一句。


五、图片

1. 按 Alt+A 选择图片，图片会出现在输入框上方。
2. 也可以把图片直接粘贴到输入框。
3. 一次最多 4 张。点图片上的叉可以去掉。
4. 单张大约不超过 6MB。
5. 和文字一起发送后，DeepSeek 会看这些图片。
6. 较早的历史图片不会一直附在后续每一轮里。


六、编译调试

点顶部「编译调试」。左侧先选范围：

系统源码
    VertexAgent 自己的程序。可改 vertex_agent、tests，以及 config.yaml、README.md、requirements.txt、start.ps1。

工作区
    用户项目。默认目录是：
    C:\Users\Yuhan\Desktop\New AI\workspace
    工作区不能设成 VertexAgent 程序目录本身，也不能设成它的上级目录。

左侧点文件名打开。点「返回上级」回到上一层目录。

编辑栏按钮：

新建
    输入相对路径，例如 hello.py 或 sensor.m，然后在编辑区写内容，再点保存。

重新载入
    放弃未保存的修改，重新读磁盘上的文件。

保存
    把编辑区写回文件。编译、调试、运行前会先自动保存。

编译
    只检查，不保留可执行文件。

调试
    以调试方式编译并运行，或对系统源码跑测试。

运行
    编译并执行，或直接执行脚本。

自我验证
    先编译，再运行。诊断结论写成「自我验证通过」或「自我验证未通过」。输出里出现 PASS 会记为通过；出现 FAIL、断言失败或程序非正常退出会记为未通过。助手改完工作区代码后也会自己做这一步。

运行参数
    填在「运行」左边。参数可空，最多 8 个，用空格分开。

发布为新版本
    先保存。再点这个按钮，写一句版本说明，不超过 200 字。
    程序会把当时的系统源码复制到 data\releases\日期时间，并写入「版本说明.txt」。
    这是本机快照，不是上传到网上。

右侧有三块输出：

实际调用指令
    这次真正执行的命令。

诊断结论
    通过，或失败原因。

程序输出
    程序打印的内容和报错。

点「同步到对话」把当前文件路径和诊断发给助手，让它按报错修改。


七、各语言怎么编译和运行

工作区里按扩展名识别：

.py
    用本机 Python。编译是语法检查。调试会打开开发模式运行。

.c
    用 gcc。编译只做语法检查。调试带调试信息后运行。运行会优化编译后再执行。

.cpp、.cc、.cxx
    用 g++，标准为 C++17。步骤与 C 相同。

.m
    用本机 MATLAB R2024b。
    编译先做语法检查，再做静态分析。语法错误会失败并带行号。未定义变量等提示写在程序输出里，但不单独判失败。通过时显示「语法检查通过」。冷启动大约 30 到 60 秒，超时为 300 秒。验收以「运行」为准，不要只看编译。
    脚本用 run 执行。函数文件按文件名调用，文件名要和函数名一致。
    不要写 input、pause、keyboard，否则批处理会停住。
    MATLAB 脚本不接收运行参数。函数可以接收运行参数。
    图窗不会弹出来，程序结束后会关闭。

.swb
    SolidWorks 宏只检查文件是否为空、本机是否安装 SolidWorks。不会启动 SolidWorks。

系统源码里：

.py
    编译是语法检查。调试是运行 tests 里的单元测试。运行是执行这个 Python 文件。
    server.py 和 __main__.py 不能再运行一份，避免启动第二个服务。

其他文本
    可以打开和保存。编译时会说明这个文件不用编译。

找不到工具时，页面会直接说明，例如没有找到 gcc、没有找到 MATLAB、没有找到 SolidWorks。


八、让助手自己改文件

在「代码」里说明要改什么。助手会自己读文件、修改、运行。步骤较多时会自动接着做，不用再发一句「继续」。

改工作区
    直接改工作区里的 C、C++、Python、MATLAB 文件，并用本机工具验证。

改系统源码
    每次修改先备份到 data\backups。
    如果改坏了 Python 语法，会自动退回修改前的内容。
    prompts.py 的改动下一轮对话就生效。其他 Python 文件要重启服务后才生效。
    管理端出现「源码已修改，重启后生效」时，点「重启服务」。
    管理端的「自身改码」可以查看这些记录。

助手不能改密钥文件，也不能把工作区指到程序目录上。


九、管理端其他项

工作区
    填一个本机目录，点「使用这个目录」。之后新建和运行的文件都在这个目录。

本机地址
    对话页底部显示当前访问地址，点「复制」可复制。

状态行
    会显示 Ollama 是否连接、当前模型、局域网地址，以及 GCC、MATLAB 是否可用。


十、局域网和 Cursor

局域网
    服务监听 8765 端口。同一局域网的电脑用「这台电脑的 IP:8765」打开页面。
    这个地址没有登录。只在可信网络里使用。
    如果其他电脑打不开，用管理员身份运行程序目录里的 open-firewall.ps1。

Cursor
    在 Cursor 的 OpenAI 兼容设置里填写：
    Base URL：http://127.0.0.1:8765/v1
    模型名：vertex-agent
    这条通道使用 VertexAgent 的编程提示词，文件修改仍以 VertexAgent 网页为准。


十一、常见情况

页面打不开
    再双击一次桌面快捷方式。确认地址是 http://127.0.0.1:8765 。

编写代码时提示需要注册 DeepSeek
    到管理端注册 API Key。

MATLAB 编译失败
    看右侧「程序输出」里的行号，改完再点编译。也可以点「同步到对话」。

MATLAB 运行没有图窗
    批处理运行不显示图窗。数值和 fprintf 的结果在「程序输出」里。

C 或 C++ 提示没有找到 gcc 或 g++
    本机需要能在命令行里运行 gcc、g++。当前约定的编译器位于 D:\mingw64\bin。

选了带 cloud 的模型后失败
    改回 DeepSeek V4.1 Flash 或本机已下载的模型。

改了系统 Python 但行为没变
    除提示词文件外，需要在管理端重启服务。
